Digital Image Processing Lab01
Introduction
    Before starting the following program, user should download MATLAB and open the main.m file via it. The input image is already
inside the same file as main.m. 

Project02_02
    In this project, the program is supposed to adjust the intensity level of the picture of a grayscale input from 256 to 
other levels, the intensity level must be the integer power of 2, ranging from 2 to 256. Thus, after pressing the "Run" button, 
the program would prompt an integer input as the intensity level. The user have to type the valid intensity level, then press
"Enter". The program shows the result image once it has done its work.

Project02_03
    In this project, the program is supposed to resize the input image within pixel replication. It could support both zooming and
shrinking. After pressing down the "Run" button, the program propmts for the scaling factor. Please input integer or decimal number.
For an example, if the scaling factor is 2, then the width and height of the image would both times by 2. If the scaling factor is
0.5, the width and height would both be 0.5 times of the origianl input. When the result image is ready, it would show the result.
Please be patient when it takes a few seconds.

Project02_04
    In this project, the programed is designed to resize the input image via bilinear interpolation. The input is all like the
previous project, but this program takes algorithm which is more complex and costs more time. Thus, it would take such long time if
the resize scaling factor and the original is relatively big. After pressing the "Run" button, the program prompts for the scaling
factor(2 for twice and 0.5 for half of both width and height). Please input the number and press enter to run the program. After 
the resized image is ready, it would show the image.
